# Predictive Analytics for Online Retail Sales Trends

## Overview
This project analyzes online retail sales trends using predictive analytics and machine learning techniques to identify the factors influencing sales performance across products, geographical regions, and time periods.

## Objective
The goal of this project is to:
- Analyze customer purchasing behavior
- Identify sales patterns and trends
- Explore geographical sales variations
- Forecast future sales trends
- Improve business decision-making using predictive analytics

## Tools & Technologies
- R
- Predictive Analytics
- Machine Learning
- Random Forest
- Decision Tree
- Multiple Linear Regression
- Data Visualization
- Exploratory Data Analysis (EDA)
- R Markdown

## Dataset
The dataset contains:
- 541,909 observations
- 8 variables

### Key Variables
- InvoiceNo
- StockCode
- Description
- Quantity
- InvoiceDate
- UnitPrice
- CustomerID
- Country

## Data Preprocessing
- Removed missing values
- Handled outliers
- Applied log transformation
- Performed exploratory data analysis

## Models Used
- Multiple Linear Regression
- Decision Tree
- Random Forest

## Model Performance

| Model | RMSE | Accuracy |
|------|------|------|
| Multiple Linear Regression | 0.4054 | 0.5946 |
| Decision Tree | 0.1651 | 0.8349 |
| Random Forest | 0.1411 | 0.8589 |

## Best Performing Model
The Random Forest model achieved the best performance with:
- Lowest RMSE: 0.1411
- Highest Accuracy: 85.89%

## Business Impact
This project demonstrates how predictive analytics can help businesses:
- Forecast sales trends
- Optimize inventory management
- Improve operational efficiency
- Reduce product returns
- Enhance customer satisfaction
